TAMER Web

Train agents using real-time feedback—no programming required.

How It Works

  1. Watch the agent act
  2. Press / for "good" or z for "bad"
  3. The agent learns your preferences

That's it. The agent builds a model of what you like and adjusts its behavior accordingly.

TAMER works best when you understand the task. Before training, try controlling the agent yourself for a few episodes using Human Control (press m to toggle, then use arrow keys or i/j/k/l). This helps you know what good behavior looks like.
